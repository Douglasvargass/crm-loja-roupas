Funcionalidades

Tudo o que o enunciado pede, com as regras que mantêm estoque e histórico sempre coerentes.

Clientes

CPF validado, endereço preenchido pelo CEP, busca sem acento e histórico de compras de cada cliente.

Produtos e categorias

Tamanho, cor, código e preço. Etiquetas de situação: Disponível, Sem estoque, Estoque baixo e Inativo.

Estoque

Entradas, ajustes com motivo e alertas de reposição. Cada movimento fica num histórico que não pode ser apagado.

Vendas

Total calculado no servidor, confirmação "tudo ou nada" que baixa o estoque e cancelamento com motivo que devolve as peças.

Dashboard

Vendas e faturamento por período, comparação com o período anterior, mais vendidos e estoque em alerta.

Perfis de acesso

Gerente, Vendedor e Estoquista, cada um vendo só o que precisa. Troca de senha obrigatória no primeiro acesso.

Assistente de IA

Pergunte em português, como perguntaria a um colega. O assistente consulta o banco de dados na hora e responde com os números reais.

  • Dados de verdade: cada resposta vem de consultas ao sistema, nada inventado.
  • Respeita o perfil: o vendedor não vê faturamento pelo assistente, assim como na tela.
  • Só consulta: não cadastra, não vende e não mexe no estoque. Quando pedem uma ação, ele explica onde fazer.
  • Conhece a loja: regras de estoque, ciclo da venda e onde fica cada função no sistema.

Como rodar no seu computador

Precisa de Java 21+, Node.js 22+ e Git. Não precisa instalar banco de dados nem Docker.

# baixar
git clone https://github.com/Douglasvargass/crm-loja-roupas.git
cd crm-loja-roupas

# terminal 1: API + banco (Windows: mvnw.cmd)
cd crm-loja-backend
./mvnw spring-boot:test-run

# terminal 2: telas
cd crm-loja-frontend
npx pnpm install
npx pnpm dev

# abra http://localhost:5173 · login gerente@loja.local · senha loja12345

Passo a passo completo, com solução de problemas: guia de comandos.
